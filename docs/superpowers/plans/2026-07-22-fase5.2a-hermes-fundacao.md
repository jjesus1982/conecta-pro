**Goal:** Subir o Hermes headless (container próprio) como orquestrador dos consultores-como-tools, com a camada de garantia embutida (proveniência/groundedness + observabilidade + auditoria + roteamento de custo + degradação graciosa), entregando os quick-wins executivos — provando a plataforma com risco contido, **sem retalho**.
