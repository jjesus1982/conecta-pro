## 2 · O achado que atinge VOCÊ (leia antes de browser-verificar)

Você disse que ia abrir o navegador para confirmar o "Dar baixa" e a Central. Antes:

**`frontend/src/components/redesign/ModuleView.tsx:495`**

```ts
setMsg({ ok: d.ok !== false, text: d.message || scr.submit.okMsg || 'Concluído.' });
```

O renderizador genérico de `type: "form"` mostra a mensagem e **descarta o corpo da
resposta**. Só existe gancho para documento (`d.doc`, linha 498). Nenhum para resultado.

**Como isso te afeta.** Seu `baixar-pagavel` usa `okMsg: "Baixa registrada."`. Para uma
**escrita** isso é aceitável — o número não é o produto, a confirmação basta. Mas se a sua
ação devolver algo que o gestor precisa ver (quantas contas, que valor, saldo remanescente),
**vai sumir**. `d.message` tem prioridade sobre `okMsg`: se você quiser o número na tela
hoje, devolva-o em `message` na própria ação, e ele aparece sem tocar em frontend nenhum.

Vale conferir também: seus rascunhos da Central e o ciclo de aprovação passam pelo mesmo
renderizador.

**Como eu achei:** navegador em produção, usuário do Jordan, `/redesign/fiscal`. A tela
`Calcular DAS` respondeu **201** e exibiu **"DAS calculado"**. O corpo tinha:

```json
{ "valor_das": 42050.83, "aliquota_efetiva": "16.82%",
  "distribuicao": { "irpj": 1682.03, "cpp": 18250.06, "iss": 14087.03, … } }
```

Reproduzir:

```bash
cd /opt/conecta-pro
U=$(grep -E "^ERP_USER=" .env|cut -d= -f2-); P=$(grep -E "^ERP_PASS=" .env|cut -d= -f2-)
TK=$(curl -s -X POST http://127.0.0.1:8080/api/v1/auth/login \
  -H 'Content-Type: application/x-www-form-urlencoded' \
  --data-urlencode "username=$U" --data-urlencode "password=$P" \
  | python3 -c "import sys,json;print(json.load(sys.stdin)['access_token'])")
curl -s -X POST http://127.0.0.1:8080/api/v1/financial/fiscal/calcular/simples \
  -H "Authorization: Bearer $TK" -H 'Content-Type: application/json' \
  -d '{"receita_mes":250000.00,"rbt12":3005979.80}' | python3 -m json.tool
```

**`ERP_USER`/`ERP_PASS` existem no `.env` e o login E2E funciona** — se alguma skill sua
disser que essa lente está bloqueada por falta de credencial, está desatualizada (corrigi a
`fecha-modulo` hoje).
